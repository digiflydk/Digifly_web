# **App Name**: DigiFly Studio

## Core Features:

- CMS-Driven Content: Fetch all textual and media content directly from Firestore CMS to ensure dynamic and easily updatable website content.
- Design Token Mapping: Dynamically map design tokens (colors, fonts, button styles) from the CMS to CSS variables for consistent styling across the application.
- Pill Button Component: Implement a reusable pill-style button component with primary, secondary, and ghost variants, customizable via CMS design settings.
- SEO Optimization: Automatically generate and include meta tags based on CMS data for improved search engine visibility. Consider creating a 'tool' to assist in this function.
- Contact Form: Allow users to send information through the 'Contact' form

## Style Guidelines:

- Primary color: Electric Blue (#1E90FF) for a modern and tech-forward feel.
- Background color: Light blue (#E5F1FF), desaturated from the primary, for a clean and unobtrusive feel.
- Accent color: Digital Purple (#6A5ACD) to complement the primary and create contrast for interactive elements.
- Headline font: 'Space Grotesk' (sans-serif) for a techy and modern feel in headings.
- Body font: 'Inter' (sans-serif) for a clean and readable text in body content.
- Use simple, geometric icons that align with the tech-focused theme.
- Maintain a clean and spacious layout with a maximum width container to ensure readability and visual appeal.
